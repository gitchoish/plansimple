## 🚀 Deployment (Simple 3 Steps)

### Step 1: Connect GitHub to Cloudflare Pages
```
1. Go to https://pages.cloudflare.com/
2. Click "Create project" → "Connect to Git"
3. Select your repo: gitchoish/plansimple
4. Choose branch: dev
5. Build command: npm run build
6. Output directory: dist
7. Click Deploy
```

### Step 2: Add Your AdSense Publisher ID
```
1. Go to https://adsense.google.com/ (sign up if needed)
2. Get your Publisher ID (pub-xxxxxxxxxxxxx)
3. Edit /public/ads.txt with your ID
4. Push to GitHub (auto-deploys)
```

### Step 3: Wait for AdSense Approval
```
- AdSense will review your ads.txt within 24-48 hours
- Once approved, ads can display automatically
- Monitor AdSense dashboard for earnings
```

**That's it!** Your site is live.
